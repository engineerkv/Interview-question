## 🧠 **Strict Format Rules Recap**

### 🔹 **Concept Section**

- Length: **1–3 lines max**
- Language: **Simple, clear, conversational**
- Focus: *What it is*, *why it matters*, *when to use it*

### 🔹 **Example Section**

- Length: **Strictly 3–6 lines of code**
- Show only **core logic** (no boilerplate)
- Keep **syntax clean**, use **tiny comments if needed**
- **Never exceed** 6 lines total

### 🔹 **Deep Insight Section**

- Must include **4–5 bullets**
- Each bullet = **unique, specific insight**
- Cover:  
  1️⃣ Rule / key idea  
  2️⃣ Real-world use  
  3️⃣ Common mistake  
  4️⃣ Optimization / advanced point  
  5️⃣ Interview tip / senior perspective

### 🔹 **Writing Style**

- Use **plain English**
- Keep it **spoken-style**, as if explaining to a teammate
- Be **concise but insightful**
- Avoid jargon unless the term is industry-standard

### 🔹 **Research Protocol**

- **ALWAYS research before answering** - verify information for accuracy
- **Check current best practices** and latest developments
- **Ensure technical accuracy** before making any changes
- **Provide comprehensive answers** based on thorough research
- **Cite sources** when appropriate for complex topics
