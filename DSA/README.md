# 🧠 DSA: LeetCode Top Interview 150

Track and organize your progress for the LeetCode Top Interview 150 study plan.

- Official plan: `https://leetcode.com/studyplan/top-interview-150/`
- Use `question.md` to track problems, status, notes, and links.

## Workflow
1. Pick a topic from the plan and open `question.md`.
2. Mark status (Todo/In Progress/Done) and add brief solution notes.
3. Add time/space complexity and references to your solution if needed.

## Topics (as grouped in the plan)
- Arrays & Strings
- Two Pointers, Sliding Window, Intervals
- Hash Map, Stack, Queue
- Linked List
- Binary Tree, BST
- Heap / Priority Queue
- Graph (BFS/DFS)
- Backtracking
- Dynamic Programming (1D & 2D)
- Math, Bit Manipulation, Simulation

Happy coding! 🚀
