# 🧩 TypeScript Interview Master List (2025 Edition)

A complete guide to TypeScript interview questions — from beginner to advanced.

---

## 🟢 1. Basic Level (Core Fundamentals)

1. What is TypeScript, and how is it different from JavaScript?  
2. What are the main benefits of using TypeScript?  
3. What are the primitive types available in TypeScript?  
4. How do you declare a variable in TypeScript?  
5. What is the difference between `let`, `const`, and `var` in TypeScript?  
6. What is a tuple in TypeScript?  
7. What is an enum, and when should you use it?  
8. What is the difference between `interface` and `type`?  
9. What is the `any` type, and when should it be avoided?  
10. What is the difference between `any`, `unknown`, and `never`?  
11. What is type inference, and how does it work?  
12. What is a union type, and how do you use it?  
13. What is an intersection type?  
14. What is the difference between optional (`?`) and default parameters?  
15. What is type casting in TypeScript, and how do you perform it?  
16. What is `tsconfig.json`, and why is it important?  
17. What are type assertions (`as` keyword), and when do you use them?  
18. What is `readonly`, and how is it different from `const`?  
19. What is structural typing in TypeScript?  
20. What are ambient declarations (`declare var`, `declare module`)?  

---

## 🟠 2. Intermediate Level (Objects, Classes, and Generics)

21. What are interfaces, and how are they used?  
22. What is the difference between extending an interface and implementing it?  
23. What are classes in TypeScript, and how do they differ from ES6 classes?  
24. What are access modifiers (`public`, `private`, `protected`)?  
25. What is `readonly` in classes?  
26. How does inheritance work in TypeScript?  
27. What are abstract classes and abstract methods?  
28. How do you use generics (`<T>`) in TypeScript?  
29. What are generic constraints (`T extends ...`)?  
30. What are default generic types?  
31. What are utility types in TypeScript (`Partial`, `Pick`, `Omit`, `Readonly`, etc.)?  
32. What is a mapped type, and how does it work?  
33. What is the difference between `keyof` and `typeof`?  
34. What is the `in` operator in mapped types?  
35. What are index signatures (`[key: string]: type`)?  
36. What is the difference between namespaces and modules?  
37. How do you import and export types and interfaces between files?  
38. What are discriminated (tagged) unions?  
39. What is type narrowing, and how does TypeScript perform it?  
40. How do you define and use function overloads in TypeScript?

## 🔵 3. Advanced Level (Type System Deep Dive)

41. What is the `never` type, and when is it used?  
42. What is the difference between `unknown` and `any`?  
43. What are conditional types (`T extends U ? X : Y`)?  
44. What are infer types (`infer U`) in conditional types?  
45. What are template literal types, and when are they useful?  
46. What are recursive types, and how can they be used?  
47. How do you define and use user-defined type guards (`arg is Type`)?  
48. What is covariance and contravariance in TypeScript?  
49. What is the difference between structural and nominal typing?  
50. What are intersection vs union types in practical terms?  
51. How do you make a deep partial or deep readonly type using recursion?  
52. What are `Exclude`, `Extract`, `NonNullable`, and `Record` utility types?  
53. How do you create strongly typed React props or Redux stores with TypeScript?  
54. What is a declaration file (`.d.ts`), and how is it used?  
55. How do you write a custom declaration file for a JS library without types?  
56. What is the `declare global` syntax, and when is it used?  
57. What is type compatibility, and how does TypeScript check it?  
58. How do you handle ambient modules and external libraries?  
59. What are decorators in TypeScript, and what must be enabled to use them?  
60. How does the experimental `emitDecoratorMetadata` option work?

73. How do you use generics with React components and hooks?
