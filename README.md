## Answer Format

### Tech Stack Questions (FE/BE)

**Location:** `FE/` and `BE/` directories

Every answer follows this format:

- **What it is**: Simple definition in everyday words
- **How it works**: Basic explanation with simple language
- **When to use**: Real project examples
- **Trade-offs**: Pros and cons, what to watch out for

**Code Examples:** Short snippets (≤4 lines)

**See:** `rule.md` - Section 1 for complete format rules

### DSA Questions

**Location:** `DSA/` directory

Every problem follows this format:

- **Problem**: Clear problem statement with constraints
- **Approach**: Brief explanation of solution strategy
- **Solution**: Complete working code with test cases
- **Time Complexity**: Big O notation with explanation
- **Space Complexity**: Big O notation with explanation

**Code Examples:** Complete functions (production-ready)

**See:** `rule.md` - Section 2 for complete format rules

### Behavioral / Project Questions

**Location:** `Projects/` directory

Every answer follows STAR method:

- **Situation**: What happened, explained simply
- **Action**: What you did, in plain language
- **Result**: Impact - numbers, feedback, outcomes
- **Takeaway**: What you learned, easy to remember

**Project Documentation:**
- **HLD (High Level Design)**: Requirements, Scope, Tech Choices
- **LLD (Low Level Design)**: Component Architecture, Data Models, APIs, Protocols, Implementation
- **Backend System Design**: Backend Architecture, APIs, Database, Scalability, Infrastructure
- **Interview Answers**: Complete STAR method answers to all interview questions

**See:** `rule.md` - Section 3 for complete format rules
