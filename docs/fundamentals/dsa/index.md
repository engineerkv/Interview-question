# 🎯 DSA Interview Preparation Guide

> **Reviewed:** 2026-09 · Modernized; legacy topics are labeled.

> **Complete roadmap for Data Structures and Algorithms interview preparation** - Organized for efficient learning and systematic study

## 📚 Preparation Order (Recommended Learning Path)

> The numbers below are the suggested *study order*, which differs from the file numbers (for example, Trie is studied 9th but lives in `13-trie.md`, while Matrix is studied 13th and lives in `12-matrix.md`). There is no file 11 - that number is intentionally unused. Every topic name links to its file.

### **Phase 1: Foundation** ⭐ Start Here

Master the fundamental data structures that form the building blocks of all algorithms.

1. **[Arrays](./01-arrays.md)** - Q1-Q33 (33 problems)
   - Two Pointers, Sliding Window, Prefix Sum, Kadane's Algorithm
   - **Time**: 3-4 days
   - **Priority**: ⭐⭐⭐ Critical

2. **[Strings](./02-strings.md)** - Q34-Q55 (22 problems)
   - String manipulation, pattern matching, anagrams, palindromes
   - **Time**: 2-3 days
   - **Priority**: ⭐⭐⭐ Critical

3. **[Linked List](./03-linked-list.md)** - Q56-Q74 (19 problems)
   - Pointer manipulation, cycle detection, merging, reversing
   - **Time**: 2-3 days
   - **Priority**: ⭐⭐⭐ Critical

### **Phase 2: Linear Data Structures** ⭐ Intermediate

Master stack, queue, and tree-based structures.

4. **[Stacks & Queues](./04-stacks-and-queues.md)** - Q75-Q86 (12 problems)
   - Stack/Queue implementation, monotonic stack, BFS patterns
   - **Time**: 1-2 days
   - **Priority**: ⭐⭐⭐ High

5. **[Binary Trees](./05-binary-trees.md)** - Q87-Q113 (27 problems)
   - Tree traversals (DFS/BFS), tree construction, tree properties
   - **Time**: 3-4 days
   - **Priority**: ⭐⭐⭐ Critical

6. **[Binary Search Tree](./06-binary-search-tree.md)** - Q114-Q123 (10 problems)
   - BST operations, validation, LCA, Kth element
   - **Time**: 1-2 days
   - **Priority**: ⭐⭐⭐ High

7. **[Heaps & Priority Queue](./07-heaps-and-priority-queue.md)** - Q124-Q135 (12 problems)
   - Heap operations, Top K problems, median finding
   - **Time**: 2 days
   - **Priority**: ⭐⭐⭐ High

### **Phase 3: Advanced Data Structures** ⭐ Advanced

Complex data structures and graph algorithms.

8. **[Graphs](./08-graphs.md)** - Q136-Q159 (24 problems)
   - DFS/BFS, shortest paths, topological sort, MST, cycle detection
   - **Time**: 4-5 days
   - **Priority**: ⭐⭐⭐ Critical

9. **[Trie](./13-trie.md)** - Q208-Q210 (3 problems)
   - Prefix tree, word search, autocomplete
   - **Time**: 1 day
   - **Priority**: ⭐⭐ Medium

### **Phase 4: Algorithmic Patterns** ⭐ Mastery

Master the most important algorithmic problem-solving patterns.

10. **[Dynamic Programming](./09-dynamic-programming.md)** - Q160-Q192 (33 problems)
    - 1D/2D DP, knapsack, LIS/LCS, string DP, optimization problems
    - **Time**: 5-7 days
    - **Priority**: ⭐⭐⭐ Critical

11. **[Recursion & Backtracking](./10-recursion-and-backtracking.md)** - Q193-Q202 (10 problems)
    - N-Queens, Sudoku, permutations, combinations, constraint satisfaction
    - **Time**: 2-3 days
    - **Priority**: ⭐⭐⭐ High

12. **[Binary Search](./14-binary-search.md)** - Q211-Q217 (7 problems)
    - Search in rotated arrays, peak finding, median problems
    - **Time**: 1-2 days
    - **Priority**: ⭐⭐⭐ High

### **Phase 5: Specialized Topics** ⭐ Optimization

Advanced techniques for optimization and edge cases.

13. **[Matrix](./12-matrix.md)** - Q203-Q207 (5 problems)
    - Matrix traversal, rotation, spiral patterns
    - **Time**: 1 day
    - **Priority**: ⭐⭐ Medium

14. **[Bit Manipulation](./15-bit-manipulation.md)** - Q218-Q223 (6 problems)
    - Bitwise operations, XOR tricks, single number problems
    - **Time**: 1 day
    - **Priority**: ⭐⭐ Medium

15. **[Math](./16-math.md)** - Q224-Q229 (6 problems)
    - Number theory, mathematical algorithms, precision problems
    - **Time**: 1 day
    - **Priority**: ⭐⭐ Medium

## 🎯 Preparation Strategy

### **For Junior/Mid-Level Roles:**

Focus on: Arrays → Strings → Linked List → Trees → Basic DP

- **Time**: 3-4 weeks

- **Coverage**: ~60% of problems (Foundation + Intermediate)

### **For Senior Roles:**

Complete all phases including advanced topics

- **Time**: 6-8 weeks

- **Coverage**: 100% of problems

### **For FAANG/Competitive Coding:**

Master all phases + practice on LeetCode

- **Time**: 8-12 weeks

- **Coverage**: 100% + additional practice

---

## 📖 Study Tips

1. **Start with fundamentals** - Arrays and Strings are the foundation

2. **Practice daily** - Solve at least 2-3 problems per day

3. **Understand patterns** - Focus on recognizing problem patterns

4. **Time yourself** - Practice solving problems within 30-45 minutes

5. **Review solutions** - Understand multiple approaches

6. **Use cheatsheet** - Quick reference for common patterns

7. **Mock interviews** - Practice explaining your approach

---

## 🔑 Key Patterns to Master

- **Two Pointers**: Arrays, Strings, Linked Lists

- **Sliding Window**: Subarray/substring problems

- **Hash Map/Set**: Lookup and frequency counting

- **Tree Traversals**: DFS (Pre/In/Post) and BFS - see [Binary Trees](./05-binary-trees.md)

- **Graph Algorithms**: DFS, BFS, Dijkstra's, Topological Sort - see the BFS vs DFS diagram in [Graphs](./08-graphs.md)

- **DP Patterns**: 1D/2D DP, Knapsack, LIS/LCS

- **Backtracking**: Constraint satisfaction problems

- **Binary Search**: Search in sorted/rotated arrays

## 📝 Notes

- Problems are organized by data structure/algorithm type

- Each problem includes solution, complexity analysis, and insights

- Practice on LeetCode for real-time validation

- Solutions use modern JavaScript (`const`/`let`, arrow functions, `Map`/`Set`, destructuring). JavaScript has no built-in heap, so heap-based answers implement a small `MinHeap` class - say so out loud in an interview.

- Focus on understanding, not just memorization

---

## 🎯 Problem-Solving Framework

1. **Understand** - Read problem carefully, identify constraints

2. **Plan** - Think about approach, data structures, edge cases

3. **Code** - Implement solution with clean, readable code

4. **Test** - Verify with test cases, handle edge cases

5. **Optimize** - Improve time/space complexity if possible

6. **Explain** - Practice explaining your solution clearly
