# 📁 Projects Directory

This directory contains detailed project documentation following High Level Design (HLD) and Low Level Design (LLD) approaches, along with interview questions about complex problems solved.

## 📋 Structure

Each project includes:
- **Question List** (`question.md`) - Interview questions about the project
- **High Level Design (HLD)** - Requirements, Scope, Tech Choices (Frontend: Web + Mobile)
- **Low Level Design (LLD)** - Component Architecture, Data Models, APIs, Protocols, Implementation
- **Backend System Design** - Backend Architecture, APIs, Database, Scalability, Infrastructure
- **Interview Answers** - Complete STAR method answers to all interview questions

## 📖 Design Document Structure

### High Level Design (HLD)

1. **Requirements**
   - Functional Requirements
   - Non-Functional Requirements

2. **Scope & Priority**
   - Phase 1: MVP (Must Have)
   - Phase 2: Enhanced Features
   - Phase 3: Advanced Features

3. **Tech Choices**
   - Frontend Framework (Web: React.js, Mobile: React Native)
   - State Management
   - API Communication
   - Additional Tools & Libraries

### Low Level Design (LLD)

3. **Component Architecture**
   - Routing Structure
   - Component Hierarchy
   - Data Sharing Strategy

4. **Data Models**
   - TypeScript/JavaScript interfaces
   - Data structure definitions

5. **Data APIs**
   - REST API endpoints
   - Request/Response formats
   - Status codes

6. **Protocols**
   - API protocols (REST, GraphQL, etc.)
   - Authentication protocols
   - Real-time communication protocols

7. **Implementation Details**
   - Pagination
   - Debouncing/Throttling
   - Error Handling
   - Caching Strategy
   - Code examples

### Backend System Design

1. **System Architecture**
   - High-level architecture diagram
   - Service architecture
   - Data flow

2. **Technology Stack**
   - Runtime and framework
   - Database and cache
   - External services
   - Infrastructure

3. **API Architecture**
   - RESTful API design
   - WebSocket events (if applicable)
   - API endpoints

4. **Database Schema Design**
   - MongoDB collections
   - Redis keys structure
   - Indexes

5. **Service Architecture**
   - Microservices structure
   - Service responsibilities

6. **Scalability & Performance**
   - Horizontal scaling
   - Caching strategy
   - Database optimization
   - Performance monitoring

7. **Security**
   - Authentication & authorization
   - Data security
   - Rate limiting

8. **Deployment & DevOps**
   - CI/CD pipeline
   - Infrastructure as code
   - Monitoring & logging

   - Follow LLD structure for detailed design
   - Reference implementation details for coding

3. **For Learning:**

   - Learn design patterns and best practices
